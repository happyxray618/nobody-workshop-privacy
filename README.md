## Deploy

1. Create the public repository `happyxray618/nobody-workshop-privacy` on GitHub (first check whether it already exists).
2. Upload the contents of this directory directly to the root of the `main` branch, preserving the two app subdirectories. Do not upload the containing directory as an extra nesting level.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Wait for the GitHub Pages deployment to succeed, then open the root and both policy URLs publicly without signing in. Verify styles and support links.
5. Configure `workHoursPrivacyUrl` with the verified Work Hours policy URL in the Android project; rebuild before release. Do not treat an unpublished URL as a completed release requirement.

This repository contains only public static pages and documentation, no SDKs, Android source, credentials, signing materials or private work records. No JavaScript, analytics, cookies or external fonts are added by these website files. The Photo Resizer policy is the existing policy copied without changing its substantive disclosures; its original Android app and original website source are preserved. Review each policy against its actual shipping version before releasing an app.
