Bad Luck Express — 개인정보 처리방침

Nobody Workshop이 제공하는 Bad Luck Express 1.1.0의 방침이에요. 최종 검토일: 2026년 10월 26일. 광고나 분석 SDK가 없는 현재 버전에 적용돼요.

계정은 필요하지 않아요. 이 앱을 통해 개발자가 개인정보나 게임 기록을 수집하거나 전달받지 않아요. HP, 휴식 시간, 뽑기 기록, 릴레이 ID와 수신 결과는 기기의 앱 전용 저장 공간에 보관해요. 언어와 처음 안내 설정도 기기에만 저장해요. Android 클라우드 백업과 앱 데이터 기기 이전은 제외돼 있어요.

받기 전 봉투 미리 보기도 기기에 저장해 앱 프로세스가 끝난 후 복원할 수 있어요. 수신 화면을 직접 나가면 지워요. 복원만으로 카드를 받거나 HP를 바꾸지 않아요.

공유는 선택 사항이에요. 코드나 링크에는 프로토콜 버전, 무작위 릴레이 ID, 공식 카드 ID, 전달 횟수, 오류 검사용 체크섬이 들어 있어요. 이름, 이메일, 연락처 목록, 위치 또는 광고 식별자는 없어요. 체크섬은 보안 서명이 아니에요. Android 앱에서 직접 받기를 선택해야 처리하며 웹 미리 보기는 HP를 바꾸지 않아요.

공유를 선택하면 Android가 선택한 글이나 은퇴 이미지를 지정한 앱에 전달해요. 해당 앱과 수신자는 각자의 정책에 따라 보관하거나 전달할 수 있어요. Nobody Workshop은 릴레이 서버를 운영하거나 수신자를 추적하지 않아요. 다른 사람이나 앱에 남은 사본은 삭제할 수 없어요.

광고 SDK, 분석 SDK, Firebase, 계정 서비스나 업무 API가 없어요. 광고 식별자나 광고 동의 창도 없어요. 나중에 광고를 도입한다면 실제 데이터 처리와 필요한 동의 기능을 먼저 설명해야 해요. 현재 광고 SDK가 광고 데이터를 처리하지 않아요.

Android 설정 → 앱 → Bad Luck Express → 저장 공간 → 데이터 삭제 또는 앱 삭제로 기기의 진행 상황을 지울 수 있어요. 반려 캐릭터, 뽑기 기록과 중복 수신 방지 기록이 영구 삭제돼요. 브라우저 사이트 데이터 설정에서 웹 언어 선택을 지울 수 있어요. 다른 앱으로 이미 공유한 사본은 별개예요.

공개 방침은 GitHub Pages에서 호스팅해요. GitHub는 호스팅과 보안을 위해 자체 개인정보 처리방침에 따라 IP 주소, 요청, 브라우저 및 기기 정보를 처리할 수 있어요: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement . Nobody Workshop은 웹 분석이나 광고 추적기를 추가하지 않으며 호스팅 로그의 보관 기간을 별도로 정하지 않아요. 미리 보기 페이지는 언어 설정만 브라우저에 저장해요. (localStorage)

카드는 오락용이며 실제 운세 예측이나 의료 서비스가 아니에요. 개인 프로필이나 자유 채팅을 수집하지 않아요. 지원 이메일을 보내면 이메일 주소와 직접 제공한 내용을 받아 문의에 답변하는 데 사용해요. 문의 처리 또는 법적 의무에 필요한 기간만 보관하며 아래 연락처로 삭제를 요청할 수 있어요.
